What the Agent Did

  • ΓÇó Executed 3 independent web searches per app to capture authentication, developer pricing, and MCP status.
  • ΓÇó Scraped official developer portals using heuristics targeting headings and auth-specific tokens.
  • ΓÇó Fed search snippets and documentation into LLM extraction with strict zero-hallucination prompting.
  • ΓÇó Enforced hard logical constraints (e.g., contact-sales apps cannot be marked build-today).
  • ΓÇó Ran autonomous verification: URL liveness, corpus keyword checks, MCP existence, and pricing conflicts.
  • ΓÇó Compiled full audit trails and hit/miss records directly into version-controlled JSON artifacts.

Where a Human Was Needed

  • ΓÇó Self-serve vs Paid-only ambiguity: SaaS apps often advertise "free sign up" when the actual API requires an Enterprise or Team plan.
  • ΓÇó Vendor vs Community MCP servers: Agents easily confuse third-party GitHub community servers with first-party official vendor tools.
  • ΓÇó Closed proprietary tools: Distinguishing open-source CLI tools (e.g. Sherlock) from hosted cloud services required domain knowledge.
  • ΓÇó Fintech underwriting: Detecting when sandbox credentials are self-serve but live merchant processing requires account reps (e.g. Ramp, Paygent).
